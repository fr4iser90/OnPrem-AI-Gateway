Budget factor (optional; enabled in Settings) scales only the grant token budget: budget_charge = max(min_tokens, estimated_prompt_tokens) × factor. Usage logs keep real tokens unchanged. factor=1 = no scaling.

{% else %}

Per-model budget factors are off (Settings → Token budget). Budget charge equals estimated prompt tokens (and min/call). Usage logs are always real tokens.
