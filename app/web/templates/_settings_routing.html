OnPrem AI Gateway behavior

Only runs when auto-sync is checked (5–1440 min). Same as Models → Sync: discovers new models; prune follows the prune checkbox. Admin notes/sampling stay.

Soft-fill (off by default): only when the client omits temperature/top_p/… and template flags (enable_thinking, preserve_thinking, reasoning_effort). Uses the model’s catalog profiles — default_profile, or X-OnPrem-Sampling-Profile / enable_thinking when the client sends them. Never overrides fields the client already set; does not invent thinking vs instruct without a signal.

Applies only when the catalog lists the same model on more than one source. load_aware uses live probes; round_robin rotates evenly per model; name is fixed alphabetical.

Strict preflight uses engine-specific APIs (/slots, /api/ps, /metrics) — no fail-open. Returns 503 + Retry-After when the backend cannot admit the request. Admission queue: holds a per-source slot (from max_concurrency or engine /props slots) with team priority until the stream ends.

Auto model aliases

Clients may send auto, auto-quality, or auto-long. Empty fields disable the rewrite for that alias slot.
